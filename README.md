# Legginx Shopify Theme

This is the production-ready Legginx Shopify theme, built for Online Store 2.0.

## Structure
- `assets/`: CSS, JS, and brand logos.
- `layout/`: Main `theme.liquid` skeleton.
- `sections/`: Modular Liquid sections (Hero, Collection, Product, etc.).
- `templates/`: JSON templates for all page types.

## Installation
Push this repository to GitHub and connect it to your Shopify store under **Online Store > Themes > Add Theme > Connect from GitHub**.
